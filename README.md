#  Lisbon Chair Shop

A modern, clean, and responsive e-commerce landing page for an artisanal chair brand, built using semantic **HTML5** and modern **CSS3** (CSS Grid & Flexbox). 

This project was developed as part of Jonas Schmedtmann's comprehensive Udemy course: **"Build Responsive Real-World Websites with HTML and CSS"**.

---

##  Project Overview

**Lisbon Chair Shop** is a landing page designed to showcase handcrafted furniture. The project emphasizes core CSS architecture, modular layouts, typography pairing, and component-based design systems.

###  Key Highlights & Sections
- **Hero Section:** Two-column grid layout pairing compelling value propositions with high-impact visuals.
- **Value Propositions & Features:** 3-column feature grid enhanced with custom inline SVG iconography.
- **Customer Testimonial:** Highlighting social proof using nested grid positioning and styled blockquotes.
- **Product Showcase Cards:** Product cards featuring dual-tier typography, specs list with custom alignment (Flexbox), pricing, and call-to-action (CTA) buttons.

---

##  Built With & Technical Implementations

- **Semantic HTML5:** Built using accessible landmarks (`<header>`, `<section>`, `<figure>`, `<blockquote>`, `<footer>`).
- **CSS Grid:** Multi-column layouts (`grid-template-columns: repeat(3, 1fr)`) with fluid column gaps.
- **Flexbox:** Fine-grained alignment for button states, list items, price bars, and SVG icons.
- **Design Systems:**
  - **Spacing System:** Structured spacing scale (2px to 128px) ensuring consistent visual rhythm.
  - **Typography Scale:** Harmonious font sizes (10px to 98px) utilizing Google Fonts (`Noto Serif`).
  - **Color Palette:** Cohesive brand identity with natural tones (`#087f5b`, `#099268`, `#343a40`).
- **Clean Components:** Reusable button modifiers (`.btn--big`, `.btn--small`) with interactive hover and focus states.
